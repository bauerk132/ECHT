## 2023-10-24 - Keyboard Focus Simulation with Playwright\n**Learning:** When using Playwright to visually verify `:focus-visible` styles, simply calling `element.focus()` may not trigger the style because the browser heuristic differentiates programmatic focus from keyboard focus. \n**Action:** You must simulate real active keyboard state by dispatching key presses (e.g., `page.keyboard.press('Tab')`) to reliably render the outline.
