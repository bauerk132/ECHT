## 2024-06-14 - Optimize Array Bottlenecks in Vanilla Render Loops
**Learning:** Chaining array methods like `.filter().reduce()` in critical render functions (e.g. `updateCategoryCounts`, `renderAnalytics`) introduces O(C*N) computational overhead and unnecessary memory allocations.
**Action:** Replace multiple-pass array method chains with single-pass `for` loops utilizing simple scalar accumulators or pre-aggregating object maps. In vanilla architectures, evaluate code dependent on pre-calculated values (like insights generation) and pass them as function arguments to avoid repetitive scoping logic errors.
