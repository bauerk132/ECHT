## 2026-09-22 - Global Focus Visible Requirement
**Learning:** Default browser focus states are often disabled or hidden in custom vanilla HTML apps. A global `:focus-visible` rule is necessary to ensure consistent and reliable visual indicators for keyboard navigation.
**Action:** Always verify keyboard accessibility manually. Add a global `:focus-visible` CSS rule (e.g., using `--echt-gold` and an outline offset) as a standard practice in these types of custom HTML/CSS apps.
