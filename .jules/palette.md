## 2026-10-02 - Ensure robust visual focus for keyboard navigation
**Learning:** Default browser focus styles for interactive elements in the vanilla HTML/CSS app are often unreliable, hidden, or overridden by custom CSS resulting in poor keyboard accessibility. Setting an explicit `outline: 2px solid var(--echt-gold)` with a `2px` offset using `:focus-visible` ensures that focus states remain clear only for keyboard navigation. Additionally, when using Playwright to test visual focus-visible styles, programmatically calling `.focus()` is insufficient as it doesn't trigger the pseudo-class style. Simulating actual keystrokes via `page.keyboard.press('Tab')` is required for reliable verification.
**Action:** Always provide a global `:focus-visible` CSS rule (e.g., using a strong accent color and an outline offset) for custom interactive elements to ensure a reliable visual indicator across all input modalities. When verifying with Playwright, always simulate keystrokes instead of just calling `.focus()`.
