💡 What
- Converted `<div>` based day selector buttons to semantic `<button type="button">` elements.
- Added `role="group"` and `aria-labelledby` to the `.day-selector` containers, linking them to their respective labels.
- Added dynamic `aria-pressed` state syncing to reflect the currently selected day.
- Added CSS resets to ensure the new buttons retain the exact same visual design.

🎯 Why
- The day selector components were previously inaccessible via keyboard navigation (Tab focus, Space/Enter to activate).
- Screen readers could not identify the group context or the active selected state of the day options.

📸 Before/After
- The visual appearance remains exactly identical. Functionality (clicking) remains the same, but now supports full keyboard navigation and screen reader compatibility.

♿ Accessibility
- Fixed missing keyboard interaction for `.day-selector`.
- Added missing ARIA attributes (`aria-pressed`, `role="group"`, `aria-labelledby`) for proper screen reader announcement of state and context.
